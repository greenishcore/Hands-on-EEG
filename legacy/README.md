# Legacy Code

This directory contains the original Jupyter notebooks and scripts from the
Hands-on-EEG project, preserved for historical reference.

| Directory | Contents |
|-----------|----------|
| `open/`   | Original app scripts (`polt.py`) and neural-network notebooks (CNN, RNN, LSTM, Transformer) |
| `new_implement/` | Early CNN and analysis notebooks |
| `normal/` | Miscellaneous exploratory notebooks |

> **Note:** These files are **not maintained**.  New development happens in
> the `src/` package.  See the root `README.md` for current usage instructions.
